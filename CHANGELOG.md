# Changelog / 更新日志

## 0.2.0-beta.1

### English

- Added English and Simplified Chinese localization for the DSH-Desktop shell.
- Added automatic system-language detection, persistent manual selection, and English fallback.
- Localized startup/error pages, native menus, version information, and update dialogs.
- Kept the upstream DeepSeek Harness interface unchanged.
- Reduced package size by retaining only English/Chinese Chromium locales and removing non-runtime metadata and foreign-architecture `node-pty` binaries.

### 简体中文

- 为 DSH-Desktop 桌面外壳增加英文和简体中文。
- 增加系统语言自动识别、手动选择持久保存和英文回退。
- 完成启动/错误页面、原生菜单、版本信息和更新对话框的本地化。
- 保持上游 DeepSeek Harness 内部界面不变。
- 仅保留中英文 Chromium 语言包，并移除非运行时元数据和其他架构的 `node-pty` 二进制，从而缩小安装包。
